# Первый запуск на серверах GitHub

Сборщик запускается на `ubuntu-latest`, поэтому ваш компьютер может быть выключен. Каждый запуск заканчивается после проверки; сайт размещается отдельно. Расписание запускает новые задания примерно раз в 15 минут, а не держит программу постоянно включённой.

## 1. Создать репозиторий

Откройте https://github.com/new и создайте **публичный** репозиторий `price-hunter`. Публичными будут исходники и товарные данные. Стандартные GitHub-hosted runners в публичных репозиториях бесплатны в пределах правил сервиса; это не обещание бесплатного бессрочного хостинга мониторинга. Условия Actions ограничивают использование как серверного приложения: https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#actions. Этот режим требует учитывать назначение и ограничения Actions; совместимость постоянного мониторинга с условиями не подтверждена GitHub.

Распакуйте `price-hunter.zip`. Загрузите **содержимое** папки `price-hunter` в корень репозитория через **Add file → Upload files**, включая `.github` и `.gitignore`. Не загружайте сам ZIP и не создавайте лишний уровень `price-hunter/` в репозитории. Ветку с исходниками назовите `main` и сделайте основной.

Проверьте наличие `.github/workflows/collect.yml`, `collector/runner.py`, `config/monitor.json` и `package.json` в репозитории. В архиве нет `.env`, `runtime`, `node_modules`, `dist` и локального кэша. При загрузке непосредственно из рабочей папки используйте Git с приложенным `.gitignore`, а не загружайте папку целиком через браузер.

## 2. Первый ручной запуск

1. Откройте **Settings → Actions → General**. Разрешите Actions и используемые проектом actions `actions/checkout` и `actions/setup-python`. В **Workflow permissions** выберите **Read and write permissions**, сохраните.
2. Откройте вкладку **Actions**. Если GitHub предлагает включить workflows, включите их.
3. Выберите **Collect prices → Run workflow**. Выберите `main`, оставьте `probe` выключенным и нажмите **Run workflow**.
4. Дождитесь завершения. В Summary проверьте количество проверенных товаров и статусы магазинов. Зелёный статус задания сам по себе не доказывает, что магазин доступен. После успешного сохранения появится ветка `price-data` с `catalog.json` и `state.json`.

Бот пока не нужен: без Telegram Secrets сборщик сохраняет цены без уведомлений. Проверка доступности магазинов с IP серверов GitHub выполняется только после реального запуска workflow. Она может отличаться от локальной проверки.

## 3. Включить расписание

После успешного ручного сбора откройте **Settings → Secrets and variables → Actions → Variables → New repository variable**:

- Name: `PRICE_HUNTER_ENABLED`
- Value: `true`

Задания запланированы на минуты **07, 22, 37, 52** каждого часа. GitHub может задерживать или пропускать scheduled jobs. В публичном репозитории расписание автоматически отключается после 60 дней отсутствия активности; его можно включить снова во вкладке Actions. Расписание работает из основной ветки: https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule.

Не нужно удерживать процесс 5 минут или добавлять 10-минутный sleep: программа завершается сразу после работы. Лимит задания — 12 минут, а не гарантированная длительность. Одновременно выполняется один сбор. Чтобы отключить новые запуски по расписанию, измените `PRICE_HUNTER_ENABLED` на `false`; выполняющееся задание отменяется отдельно во вкладке Actions.

## 4. Telegram и сайт позже

Когда создадите бота, добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` во вкладке **Secrets**. Не помещайте их в Variables, исходники или сообщения в чате.

Этот workflow запускает сборщик и сохраняет данные. Для публикации интерфейса нужны отдельные шаги Cloudflare Pages из `README.md`, разделы 4–5. Прежде чем публиковать интерфейс, выполните первый сбор, чтобы существовала ветка данных.

Если потребуется собственный исполнитель вместо серверов GitHub, добавьте Repository Variable `PRICE_HUNTER_RUNNER_LABELS` со значением `["self-hosted", "price-hunter"]` и подключите runner с меткой `price-hunter`. При отсутствии этой переменной используется `ubuntu-latest`.
